# Code of Conduct

## Our standard

PrintScale Studio is a small project, and we want it to be a welcoming place for everyone who uses it or contributes
to it, whatever their background, experience or identity.

Expected behaviour:
- be respectful and patient, especially with newcomers and people writing in a second language;
- give and accept constructive feedback about code and ideas, not about people;
- stay on topic, and assume good intent.

Not acceptable:
- harassment, insults, or discriminatory jokes and language;
- personal or political attacks;
- sharing someone's private information without permission;
- sexualised content;
- deliberately disruptive behaviour;
- spam.

This applies to all project spaces: issues, pull requests, discussions and reviews.

## Reporting

If someone's behaviour concerns you, report it privately to the maintainer using the repository's private
reporting form: [Report privately](https://github.com/baki2222/printscale-studio/security/advisories/new). Start the
title with **"Conduct:"**. It is only visible to the maintainer. You can also use GitHub's
[Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature for any comment or issue.

Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, close or lock threads, or block participants who break this code.
Usually the first step is a private warning.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
